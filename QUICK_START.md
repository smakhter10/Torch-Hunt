# 🚀 QUICK START GUIDE

## Get the game running in 3 steps:

### Step 1: Install Dependencies
```bash
cd torch-hunt
npm install
```

### Step 2: Start the Game
```bash
npm run dev
```

### Step 3: Play!
Open your browser to the URL shown (usually `http://localhost:5173`)

---

## 🎮 Controls Summary

**Desktop:**
- Move mouse → Control torch
- Click → Toggle torch ON/OFF
- Mouse wheel → Adjust torch size
- Click treasures → Collect them

**Mobile:**
- Touch & drag → Control torch
- Tap screen → Toggle torch ON/OFF
- Use slider → Adjust torch size
- Tap treasures → Collect them

---

## ✨ What to Expect

1. The game starts with a dark screen
2. Move your mouse/finger to activate the timer
3. Use the torch to search for 10 hidden treasures
4. Treasures glow when visible in the torch light
5. Click/tap them to collect
6. Find all 10 as fast as you can!
7. Your final time will be displayed when complete

---

## 🎯 Tips

- Start with a larger torch to scout the room
- Reduce torch size for precise searching in tight spots
- Move systematically to avoid missing areas
- Treasures are randomly placed each game
- Toggle torch OFF briefly to remember positions
